# Infinity Android project plan

Android AI assistant with hybrid local/cloud model routing, voice interaction, phone-to-desktop pairing, permissions, and privacy controls.

## Required deliverables

- Complete source project
- Reproducible build configuration
- Automated build checks
- Release artifact only after a successful verified build
- No committed API keys or private credentials

## Safety and privacy

Sensitive permissions must be explained in-app, minimized, and revocable. Features that affect device access or location require clear user consent.
